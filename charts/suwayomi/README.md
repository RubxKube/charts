Suwayomi is a free and open source manga reader server that runs extensions built for Mihon (Tachiyomi). It bundles a web UI and can be used remotely from any compatible client.

## Notes

- **Probes:** the startup probe targets `/login.html` rather than `/`. Suwayomi
  exempts `/login.html` from authentication in every auth mode
  (`none` / `basic_auth` / `simple_login` / `ui_login`), so it always returns
  `200`. Using `/` would return `302` (simple/ui login) or `401` (basic auth)
  once authentication is enabled, which Kubernetes `httpGet` probes treat as
  failure (only `2xx`/`3xx < 400` count as success).
- **Persistence:** a single PVC (`data`) is mounted at
  `/home/suwayomi/.local/share/Tachidesk`, which holds the database, config,
  extensions, WebUI cache and downloaded manga. If you later split downloads
  onto a separate volume, it **must be listed before** the `data` volume in
  `common.persistence.volumes` or the downloads subpath will be shadowed by the
  parent mount (see the upstream Docker notes).
- **Security:** the container image runs as a non-root user (`uid`/`gid` 1000).
  `podSecurityContext.fsGroup: 1000` is set so the PVC (root-owned by default)
  is writable by that user.
- **FlareSolverr:** this repository ships a [`flaresolverr`](../flaresolverr)
  chart. Deploy it alongside and set `FLARESOLVERR_ENABLED: "true"` and
  `FLARESOLVERR_URL: http://flaresolverr:8191` under
  `common.variables.nonSecret` to let Suwayomi bypass Cloudflare challenges.
